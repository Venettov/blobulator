Bundled ubiquitin demonstration data

Contents
  ubiquitin.psf   Structure/topology: 26,190 atoms, including solvent and ions.
  pulling.dcd     Matching 100-frame pulling trajectory.
  SHA256SUMS      SHA-256 checksums of these two unmodified data files.

Click Load ubiquitin demo in Blobulator, then Blobulate. The GUI selects protein
for blobulation (76 residues). The full original solvated system is retained;
no atoms or frames have been removed and no coordinates have been generated,
resampled, smoothed or otherwise changed. The approximately 34 MB bundle works
offline and requires no separate tutorial download, Git LFS or Python package.
Keep this directory inside VMD_scripts when copying the extension.
